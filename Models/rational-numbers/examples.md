# Rational Numbers Examples

## Example 1: A Logical Ratio

`1 ▷ (1 : 2) : 2 ⊢ 2 ≢ 0`

The ratio `(1 : 2)` is logical because it has finite components and its denominator is nonzero.

## Example 2: Equivalent Ratios

`Mul(1, 4) ≣ Mul(2, 2)`

`(1 : 2) ≣ (2 : 4)`

The two ratio structures represent the same rational structure.

## Example 3: Addition

`(1 : 2) ⊗ Add ⊗ (1 : 3) ↓ (Add(Mul(1, 3), Mul(1, 2)) : Mul(2, 3))`

`↓ (5 : 6)`

## Example 4: Multiplication

`(2 : 3) ⊗ Mul ⊗ (3 : 5) ↓ (Mul(2, 3) : Mul(3, 5))`

`↓ (2 : 5)`

## Example 5: Rational-Number Totality

`Q = P ⟳ P ⊢ F(P)`

Under `F(P)`, another finite ratio may be associated with `P`. The totality has no final ratio structure, even though each ratio structure is logical.

## Example 6: Model References

`★ = (N ∧ Z ∧ Q ∧ P ∧ F ∧ Add ∧ Mul)`
