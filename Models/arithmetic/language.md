# Arithmetic Language

## References

| Reference | Meaning |
|---|---|
| `0` | The origin numeral. |
| `N` | The natural-number totality. |
| `I` | The successor interaction. |
| `S` | The successor form. |
| `A` | The addition interaction. |
| `M` | The multiplication interaction. |
| `D` | The truncated-subtraction interaction. |
| `≤` | The non-strict order relation. |

## Numerals

`S(x) = (x ⊗ I)`

A canonical numeral is `0` or `S(x)` where `x` is canonical. Write `n` for any canonical numeral, not as an additional primitive.

## Arithmetic Forms

`Add(x, y) = (x ⊗ A ⊗ y)`

`Mul(x, y) = (x ⊗ M ⊗ y)`

`Sub(x, y) = (x ⊗ D ⊗ y)`

`x ≤ y` is a judgment, not an arithmetic structure. It is generated by the order rules.

## Structural Equality

`x ≣ y` means that two canonical numerals have the same successor construction. `x ≢ y` is its negation.
