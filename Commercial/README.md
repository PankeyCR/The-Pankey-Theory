# Commercial Workspace

Use `Commercial/private/` for unpublished product code, client data, service templates, proposals, credentials, pricing details, and other commercial materials. This path is excluded from Git by the root `.gitignore`.

Do not place customer material, API keys, private hardware designs, or proprietary implementation details in public folders.

The public theory and the proprietary website have separate licensing described in [LICENSING.md](../LICENSING.md).
